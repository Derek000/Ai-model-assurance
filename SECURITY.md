# Security policy

This is experimental defensive research software. Do not submit credentials, private model weights, sensitive prompts or live exploitation details in public issues.

For a vulnerability in this repository, use GitHub's private vulnerability reporting feature if enabled, or contact the maintainer privately through a channel explicitly listed on the GitHub profile. Do not publish working exploit details before coordination.

Run untrusted models and optional scanners in disposable, unprivileged, network-restricted environments. No scanner can guarantee the absence of a model backdoor.
