# References and further research

## Defensive tooling
- [ModelAudit](https://github.com/promptfoo/modelaudit) — model artefact static inspection.
- [ModelScan](https://github.com/protectai/modelscan) — unsafe model format inspection.
- [Fickling](https://github.com/trailofbits/fickling) — pickle security analysis.
- [Garak](https://github.com/NVIDIA/garak) — LLM vulnerability testing.
- [Inspect AI](https://inspect.aisi.org.uk/) — evaluation framework.
- [LM Evaluation Harness](https://github.com/EleutherAI/lm-evaluation-harness) — repeatable model evaluation.

## Model formats and deployment
- [Safetensors](https://huggingface.co/docs/safetensors/index) — safe tensor serialisation.
- [Hugging Face security guidance](https://huggingface.co/docs/hub/security) — model repository security.
- [Ollama API](https://docs.ollama.com/api) — local inference interface.
- [OpenAI-compatible vLLM server](https://docs.vllm.ai/en/latest/serving/openai_compatible_server/) — alternative inference interface.

## Threat modelling and standards
- [MITRE ATLAS](https://atlas.mitre.org/) — adversarial threats to AI systems.
- [OWASP GenAI Security Project](https://genai.owasp.org/) — LLM and agent risks.
- [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework) — risk management.
- [NIST AI 100-2](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-2e2025.pdf) — adversarial machine learning taxonomy.

These are external resources, not endorsements or claims that each tool detects weight-level backdoors. Verify version compatibility and licensing before use.
